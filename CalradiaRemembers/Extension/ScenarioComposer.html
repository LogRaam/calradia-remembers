Calradia Remembers — Scenario Composer

Build scripted-scenario packs without writing JSON by hand.

How it works. A scenario is a stateless reactive rule: when its trigger fires and its guards pass, its consequences mutate the world and its message is told in game. If several rules share a trigger, one is chosen at random.
1) Add rules below. 2) Download pack. 3) Drop the file into scenarios in your Custom folder (Modules/CalradiaRemembers/ModuleData/Custom/scenarios/, or the Custom folder set in MCM), which CR updates never replace. A mod ships its packs in its own ModuleData/cr_scenarios/. Give each rule an id of its own, and name heroes and kingdoms by their game id (lord_1_14, empire_s): names are translated. 4) In game: cr.scenarios to list them, cr.scenario_fire ON_DEATH Rhagaea to test one.
