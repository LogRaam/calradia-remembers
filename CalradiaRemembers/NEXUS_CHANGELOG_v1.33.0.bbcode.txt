[size=4]v1.33.0[/size]

Two features for players who like to tinker with the writing, plus a couple of quiet improvements. Saves carry over untouched.

[size=3][b]Added[/b][/size]
[list]
[*][b]A Custom folder that survives updates.[/b] The prompt files that shape how characters write (world.txt, player_description.txt, post_history_instructions.txt, the behaviour guidelines) and your narrative styles all live in ModuleData, next to the mod's own files, so editing them directly meant an update would overwrite your work. There is now a ModuleData/Custom folder: drop a copy of any of those files there (keep the same name), or put a style in Custom/Styles, and the mod loads yours first and never touches it on update. See the README inside the folder.[/*]
[*][b]Template variables in your prompts and styles.[/b] Text you author (styles, and the prompt files above) now understands SillyTavern-style {{token}} variables, filled in fresh for the character you are actually talking to and the hero you actually are: {{char}}, {{char_gender}}, {{user}}, {{user_gender}}, {{user_clan}}, {{faction}}, {{location}}, {{spouse}}, {{father}}, {{mother}}. So one style file writes correctly for every character instead of naming whoever you first used it with. Case does not matter, and an unknown token (a typo) is left as written instead of vanishing. The full list is on the mod page and in the Custom README.[/*]
[/list]

[size=3][b]Improved[/b][/size]
[list]
[*][b]Characters stay consistent through long conversations.[/b] In a long exchange (above all a gathering of several characters at once), the earlier part of the talk is now folded into a compact running recap that every speaker is given, so no one loses track of what was said or agreed to earlier, without the prompt growing without bound. Short conversations are untouched.[/*]
[/list]

[size=3][b]Fixed[/b][/size]
[list]
[*][b]A lord no longer "agrees" to peace or a parley in conversation.[/b] War and peace between realms are a ruler's strategic decision, not something settled in a chat, so a character can no longer talk as if concluding a truce or committing their faction to a negotiation on the spot: they now defer it to their liege, closing off a promise the game could never actually keep.[/*]
[/list]
