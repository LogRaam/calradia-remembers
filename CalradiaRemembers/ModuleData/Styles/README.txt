CALRADIA REMEMBERS, NARRATIVE STYLES

Every .txt file in this folder is a STYLE: a set of rules describing HOW the AI writes, not who the
characters are. The file name is the name you will see in the game's style picker, so "Novelistic.txt"
shows up as Novelistic.

A style is injected into every conversation, adult scenes included, and is shared by both models (the
roleplay one and the NSFW one). It never changes a character's personality, what they know, or what
they are willing to do: those are decided elsewhere and always win.

To write your own: copy one of these files, rename it, and edit the text. Plain English instructions
work best, in the second person ("Write in...", "Keep...").

You can edit a style WHILE PLAYING: save the file and your next message uses the new rules, with no
restart. Switching style in the picker takes effect on your next message too.

In game:
  cr.style_ui on      shows the style button in the chat window's header
  cr.styles           lists every style found here, and which one is active
  cr.style <name>     picks one from the console
  cr.style_show       prints exactly what is being injected right now
