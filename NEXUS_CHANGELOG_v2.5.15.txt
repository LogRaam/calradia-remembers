Version 2.5.15

A small release, almost entirely for anyone who uses a bridge mod or writes one. All four fixes came out of reading the first real bridge built on this mod's modder API, tashmetu's Bellum Bridge, against the code. Its author sent the files over rather than describing them, and every one of these was invisible from the outside.

Fixed

- Disabling a bridge mod in the launcher now actually switches it off. Since 2.5.13, the mod read the prompt text contributed by every module it found on disk, including ones you had turned off. Worse, a disabled bridge no longer registers its own placeholders, so its text could reach the characters with the placeholders still in it, as raw {{names}} in braces, on every turn. Only modules you have enabled are read now, and in the order the launcher loads them, which is what the 2.5.13 notes promised and did not deliver. If you ever disabled a bridge to troubleshoot something and characters got strange afterwards, this is likely why.

For modders

- Placeholders now work in the behaviour guidelines too. A {{name}} registered through the modder API was filled in everywhere else in the prompt but reached the model as the raw placeholder in this one file, with nothing to tell you so. It is filled in here now, in both the full and the compact prompt. One thing worth knowing: this file is part of the cached portion of the prompt, so use it for values that change rarely, and put anything that changes turn to turn in post_history_instructions.

- A contribution to the behaviour guidelines reaches every character again, not only Nords. The guidelines end with a section per culture, and each character keeps only their own. Text added after the file with no heading of its own was absorbed into the last of those sections, which happens to be the Nords, and removed for everyone else without a word. Each module's contribution now gets its own section automatically. If you already open yours with a heading, as the Bellum Bridge does, nothing changes and nothing is doubled.

- Comments. A line starting with !# in a contributed file is for you and is never sent to the model. Until now every line that was not a directive went to the characters, so a note like "this file is appended after your Custom folder" was being read by every lord in Calradia on every turn. A file containing nothing but comments leaves the text exactly as the mod shipped it.

Notes

- Nothing here changes your save format and nothing needs a new game.

- If you use a bridge mod: this is the version where disabling it in the launcher is enough. On 2.5.13 and 2.5.14, remove its folder instead.
