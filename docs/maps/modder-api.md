# Modder API: the public surface other mods are built against

GENERATED by the Maps fixtures in `CalradiaRemembers.Tests/Maps`. Do not edit. A test fails when this file
no longer matches the code; see `docs/maps/README.md`.

**This is a contract with other people's mods.** A line ADDED here is a new capability. A line REMOVED or
CHANGED is a breaking change for every bridge already shipped, and belongs in the release notes under "For
modders", with the version it happened in. The surface is everything public under an `Extension` folder.
