# Modder API: the public surface other mods are built against

GENERATED by the Maps fixtures in `CalradiaRemembers.Tests/Maps`. Do not edit. A test fails when this file
no longer matches the code; see `docs/maps/README.md`.

**This is a contract with other people's mods.** A line ADDED here is a new capability. A line REMOVED or
CHANGED is a breaking change for every bridge already shipped, and belongs in the release notes under "For
modders", with the version it happened in. The surface is everything public under an `Extension` folder.

- `IReadOnlyList<ResolvedEntity> MentionedFactions { get; }`
- `IReadOnlyList<ResolvedEntity> MentionedHeroes { get; }`
- `IReadOnlyList<ResolvedEntity> MentionedSettlements { get; }`
- `VerbFacts Npc { get; }`
- `bool IsEligible { get; }`
- `string PlayerMessage { get; }`

### ActionRequest

_One invocation of an external verb: which one, its parsed [ACTION] parameters, and the live facts._

- `IReadOnlyDictionary<string, string>? Parameters { get; set; }`
- `VerbFacts Facts { get; set; }`
- `string VerbName { get; set; }`

### ActionResult

_The outcome of executing an external verb, mirrored back into the host's own chat-line outcome._

- `bool Success { get; set; }`
- `string Message { get; set; }`
- `string? Recap { get; set; }`

### ExternalVerbContract

_An externally-defined conversation verb: its name (the [ACTION] "type:" it answers to), whether it currently applies, what it teaches the LLM, and how it executes._

- `Func<ActionGuidanceContext, string>? Guidance { get; set; }`
- `Func<ActionRequest, ActionResult>? Execute { get; set; }`
- `Func<VerbFacts, bool>? IsEligible { get; set; }`
- `Func<VerbFacts, string>? TeachingText { get; set; }`
- `string Name { get; set; }`

### PromptVarFacts

_The engine-agnostic facts a registered prompt-variable provider (see PromptVariableRegistry) reasons over._

- `IReadOnlyDictionary<string, string>? Extra { get; set; }`
- `bool CouncilSeat { get; set; }`
- `bool Lean { get; set; }`
- `int RelationToPlayer { get; set; }`
- `string NpcId { get; set; }`

### PromptVariableRegistry

_Holds the registered name -> provider table for live prompt variables._

- `static IReadOnlyDictionary<string, string> Compose(PromptVarFacts facts)`
- `static bool Unregister(string name)`
- `static void Register(string name, Func<PromptVarFacts, string> provider)`

### ResolvedEntity

_One entity the player mentioned, as the host resolved it: its stable engine id, a display name, and an optional short note (e.g. a hero's relation category to the NPC)._

- `ResolvedEntity(string id, string name, string? note = null)`
- `string Id { get; }`
- `string Name { get; }`
- `string? Note { get; }`

### VerbFacts

_The engine-agnostic facts about the conversation partner an ExternalVerbContract's callbacks reason over: who they are, their standing, and their relation to the player._

- `IReadOnlyDictionary<string, string>? Extra { get; set; }`
- `bool IsFemale { get; set; }`
- `bool IsLord { get; set; }`
- `bool IsPrisoner { get; set; }`
- `int RelationToPlayer { get; set; }`
- `string NpcId { get; set; }`
- `string? FactionId { get; set; }`
