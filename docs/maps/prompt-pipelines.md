## Prompt profiles

A prompt profile (MCM *Prompt Profile*, `ModuleData/Custom/Prompts/`) reorders, rewords or turns off the sections of
`prompt-sections.md`. Of the prompt builders, only those that use `PromptLayout` are reached: `PromptBuilder`.
Every other pipeline above writes its prompt the same whatever profile is chosen.
