no longer matches the code; see `docs/maps/README.md`.

**This is a contract with every campaign in progress.** Keys are ADDITIVE ONLY: a renamed or removed key is a
player's data silently gone on their next load, and nothing fails when it happens. A key that disappears from
this file is refused by the suite, regeneration included, until it is declared on purpose.

## Saveable type ids

The engine reconciles a save by the raw NUMBER, not the type name, so a changed id orphans old saves and a
reused one crashes the boot when another mod holds it.
