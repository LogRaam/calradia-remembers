# Prompt sections: the system prompt, in the order it is written

GENERATED by the Maps fixtures in `CalradiaRemembers.Tests/Maps`. Do not edit. A test fails when this file
no longer matches the code; see `docs/maps/README.md`.

**Zone.** `prefix` is sent as the cacheable part of the prompt and must not change between two turns of one
conversation. `tail` follows `AppendEncounterContext`, which writes the marker the cache is split on, and is sent fresh
every turn. A fact that is true on one turn and gone the next belongs in the tail, always.

**Compact.** `dropped by policy` names the `PromptSection` the compact (Lean) prompt may leave out; `aware` means
the section is handed the level and decides for itself; blank means it is written the same in both.

**Key and lock.** The key is what a prompt profile's layout and text files name (a contract: never renamed once
shipped). `sealed`: cannot be turned off, moved or reworded; `required`: cannot be turned off; blank: free.
