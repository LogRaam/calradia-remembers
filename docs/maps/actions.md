# Actions: where a character acts or is placed before the player, and the gate each one asks

GENERATED by the Maps fixtures in `CalradiaRemembers.Tests/Maps`. Do not edit. A test fails when this file
no longer matches the code; see `docs/maps/README.md`.

Every initiative, and every action a character takes when the player summons them (a council seat), asks
`ActionGate` (the live side of `NpcActionGate`): the character is alive, in the world (not disabled),
of age (`Hero.IsChild`, never a rank: `IsLord` is an occupation; a council seat takes the council's own age,
13), free, and not the player. Each path keeps its own conditions on top. Answering the player (a reply), being
the subject of news, and the verbs a model emits in conversation have their own rules.

## `IsAlive` read on its own

The engine's `Hero.IsAlive` means only "not dead": a hero the game has taken out of the world (disabled)
reads alive, and `Clan.Heroes` keeps both the dead and the disabled. A check that means "may act" asks
`ActionGate`; one that means "is in the world" asks `HeroPresence.IsInTheWorld`. What is left below is
the backlog (a baseline in `RatchetTests` that may only go down); many are bookkeeping ("is the subject of
this memory still alive") where death alone is the question.
