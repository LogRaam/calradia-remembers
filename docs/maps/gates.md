# Gates: what opens a verb, and what the bridge demands of it

GENERATED by the Maps fixtures in `CalradiaRemembers.Tests/Maps`. Do not edit. A test fails when this file
no longer matches the code; see `docs/maps/README.md`.

`verbs.md` says whether an action is DECLARED everywhere it must be. This says whether the condition that
TEACHES it and the condition the bridge ENFORCES on it are the same condition, and what can change the
answer between them.

- **Taught when**: the guard on the prompt section that names this action (`"type: <action>"`), read from
  the section's own early returns and from the `if` around its call.
- **The bridge refuses when**: every `ActionOutcome.Refused` the executor can return. These are the
  promises the verb can break.
- **Can be invalidated mid-turn by**: other actions whose executor WRITES state this action's teaching
  gate READS. The context is built at the start of a turn and the bridge runs at the end of it, so such an
  action can be honestly untaught and honestly executable in the same turn. A POSSIBILITY in the code,
  never a claim that it happened.

Two conditions on one line do not prove they agree. That comparison is the reader's, and it is the whole
point of putting them there.

## Worth a look

### Taught under a condition, refused by nothing (8)

The prompt decides alone. Fine for an action that cannot fail, and the shape of an empty promise otherwise: the model is told it may, and the bridge never re-checks that it still may by the time it runs.

- `change_relation`
- `give_influence`
- `give_troops`
- `impregnation_risk`
- `lend_troops`
- `pay_for_silence` <- `join_clan`, `recruit_prisoner`, `turn_nemesis` (via Clan)
- `recall_companion` <- `join_clan`, `recruit_prisoner`, `turn_nemesis` (via Clan)
- `release_prisoner`

### Refused by the bridge, taught with no gate of its own (10)

The model is taught this every turn the section is written and the bridge turns it away on the facts. Fine when the refusal is rare; an empty promise when it is not (the join_party rule).

- `accept_divorce`
- `decline_divorce`
- `end_own_marriage`
- `execute_player`
- `execute_prisoner`
- `gather_news`
- `harm_prisoner`
- `pay_blackmail`
- `take_gold`
- `turn_nemesis`

### A gate another action can invalidate in the same turn (8)

Not a defect by itself. It is the reason an "executed but was not taught this turn" audit line can be true AND the code correct, which is exactly the trap that cost a triage on 22/09/2026.

- `close_relationship` <- `end_affair` (via LoverKnownToPlayer, TakenLoverId)
- `grant_blessing` <- `join_clan`, `recruit_prisoner`, `turn_nemesis` (via Clan)
- `open_relationship` <- `close_relationship`, `give_prisoner`, `marry`, `take_as_consort`, `take_as_secret_lover` (via IsConsort, IsOpenArrangement, Status)
- `pay_for_silence` <- `join_clan`, `recruit_prisoner`, `turn_nemesis` (via Clan)
